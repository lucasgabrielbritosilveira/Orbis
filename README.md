# Orbis Equalizer

Equalizador de áudio global para KDE Plasma 6 utilizando PipeWire e C++.

## Como testar e rodar localmente:

1. Torne o script de deploy executável e execute-o:
   ```bash
   chmod +x deploy.sh
   ./deploy.sh
   ```
2. Adicione o plasmoid **Orbis Equalizer** ao seu painel ou área de trabalho do KDE Plasma.
